Pressing a cell XORs it and its four neighbours, so each of those bits flips. Clear the board to 0.

    Modes and the maths

    Every press is its own undo, because XOR twice is nothing (a ⊕ b ⊕ b = a). And the order of presses never matters. So a solution is just a set of cells, each pressed once or not at all.

    That turns the puzzle into linear algebra over GF(2), the arithmetic of a single bit. The hint button solves the equations with Gaussian elimination, then picks the shortest answer. On a 5×5 board some patterns can't be solved at all, but every puzzle here is built from real presses, so it always has an answer.
