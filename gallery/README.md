# Nyx Web Gallery

Four small web experiments, written by hand in plain HTML, CSS and JavaScript. No frameworks, no build step, no trackers and no external requests.

| Site | What it is |
|---|---|
| [Logic Lab](logic-lab/) | Logic gate playground: place gates, draw wires, flip switches, get the truth table. Includes examples such as a full adder and an SR latch. |
| [Signal Studio](signal-studio/) | Browser oscilloscope: Fourier synthesis, an exact RC low-pass filter, and time, XY and spectrum views, with optional audio. |
| [Driftfield](driftfield/) | Generative art: seeded particles follow a Perlin noise field. You can stir it, add symmetry and save a PNG. |
| [Bitflip](bitflip/) | XOR puzzle (Lights Out) with levels, a wrap-around mode and a GF(2) Gaussian-elimination hint solver. |

Every page works with a keyboard and respects `prefers-reduced-motion`. All paths are relative, so the site works from any sub-path on GitHub Pages.
